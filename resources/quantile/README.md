# QuantileKit

Calibrated interval forecasting utilities. Part of the Beacon Metrics research program.

## Release Status

**Released** — v0.9.1 is published to the internal package index.

This code tree contains the implementation described in our Q4 technical report.

## Layout

- `src/` — library code
- `data/` — small sample fixtures
- `experiments/` — training and evaluation configs
- `notebooks/` — quickstart notebooks
- `results/` — reference metric outputs
- `tests/` — smoke tests

## Getting started

See `notebooks/quickstart.ipynb` for a minimal example.
